# 数据策划艺术

> "数据策划是最大性能增益的来源。"

数据是语言模型训练的基础。训练数据的质量和组成直接决定模型能力。

## 数据混合的反直觉本质

### 核心挑战

- 不同领域争夺训练预算
- 提高一个来源的权重 = 降低其他来源的权重
- 过度重复使用高质量数据可能有害

## 训练课程 (Curriculum)

### 演进：单阶段 → 多阶段

- **训练前期**：高权重充足数据源
- **训练后期**：引入小规模高质量数据

### 阶段划分策略

1. **性能驱动干预**（监控基准调整）
2. **将高质量数据留给退火阶段**

## SmolLM3 数据混合

### 三阶段训练

| 阶段 | Tokens | Context | 数据构成 |
|------|--------|---------|---------|
| Stage 1 | 8T | 4k | Web 基础混合（FineWeb-Edu + DCLM 50/50）+ 10% 代码 + 3% 数学 |
| Stage 2 | 2T | 4k | 添加 Stack-Edu、FineMath4+、MegaMath |
| Stage 3 | 1.1T | 4k | 上采样高质量数据 + OpenMathReasoning |

### 关键发现

- **多语言 web 数据占 12%**：英语不退化前提下的最优平衡
- **代码占比从 25% 降至 10%**：避免英语基准下降

## 数据质量指标

### 需要关注什么

| 指标 | 描述 |
|------|------|
| **教育价值** | 内容是否教授知识？ |
| **事实准确性** | 信息是否正确？ |
| **语言质量** | 写作是否良好？ |
| **重复度** | 内容是否重复？ |

### 过滤策略

```python
# 示例：质量过滤流水线
def quality_filter(dataset):
    # 步骤 1: 去除重复
    dataset = remove_exact_duplicates(dataset)

    # 步骤 2: 语言检测
    dataset = filter_by_language(dataset, target_langs)

    # 步骤 3: 质量评分
    dataset = score_and_filter(dataset, min_quality=0.7)

    # 步骤 4: 去除个人信息
    dataset = remove_pii(dataset)

    return dataset
```

## 数据混合比例

### 平衡艺术

| 领域 | 权重 | 理由 |
|------|------|------|
| Web 文本 | 60-70% | 广度、多样性 |
| 代码 | 10-25% | 推理、结构 |
| 数学 | 3-10% | 数值推理 |
| 多语言 | 10-15% | 跨语言迁移 |

### 警示信号

- ⚠️ 代码过多 → 英语回归
- ⚠️ 多语言过多 → 英语退化
- ⚠️ 多样性不足 → 过度拟合模式

## FineWeb 数据集经验

### 有效的做法

- ✅ 质量过滤优先于数量
- ✅ 教育内容加权
- ✅ 多样化来源以提高鲁棒性

### 无效的做法

- ❌ 纯高质量学术文本（损害小模型）
- ❌ 激进去重（丢失稀有模式）
- ❌ 单来源主导（制造偏见）

## 关键要点

1. **数据策划是最大的性能杠杆**
2. **多阶段训练让你更高效地利用数据**
3. **谨慎平衡领域——注意回归问题**
4. **对于小模型：质量 > 数量**
