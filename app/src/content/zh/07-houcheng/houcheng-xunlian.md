# 后训练

后训练将基础语言模型转变为一个有用、对齐的助手。本章涵盖关键技术。

## 为什么需要后训练？

基础模型的训练目标是预测下一个 token —— 它们不是天生的有用助手。

### 差距

| 能力 | 基础模型 | 后训练后 |
|------|---------|---------|
| 遵循指令 | ❌ | ✅ |
| 安全对齐 | ❌ | ✅ |
| 对话能力 | ❌ | ✅ |
| 任务完成 | ❌ | ✅ |

## 监督微调 (SFT)

### 什么是 SFT？

在高质量演示数据上微调预训练模型。

### 数据要求

| 质量维度 | 描述 |
|---------|------|
| **回复质量** | 展示期望行为 |
| **格式一致性** | 遵循对话结构 |
| **多样性** | 覆盖各种任务 |
| **长度** | 平衡，不太短/太长 |

### 训练配置

```yaml
# SFT 配置
learning_rate: 2e-5
batch_size: 8-32
epochs: 1-3
max_seq_length: 4096
warmup_ratio: 0.1
```

### 常见问题

- ⚠️ **过拟合**：小数据上训练太多 epoch
- ⚠️ **欠拟合**：训练不够
- ⚠️ **格式回归**：模型忘记结构

## 直接偏好优化 (DPO)

### 什么是 DPO？

DPO 直接在偏好数据上优化模型，无需奖励建模。

### DPO 工作原理

```
传统 RLHF:  Policy → Reward Model → RL Optimization
DPO:         Policy → Direct Preference Optimization
```

### DPO 损失

```
L_DPO = -log(σ(log π(y⁺|x) / π₀(y⁺|x) - log π(y⁻|x) / π₀(y⁻|x)))
```

###何时使用 DPO

| 场景 | 建议 |
|------|------|
| 偏好数据有限 | 先用 SFT |
| 安全问题 | DPO 可帮助 |
| 复杂推理 | SFT + DPO |
| 简单任务 | SFT 足够 |

## 人类反馈强化学习 (RLHF)

### 三步流程

1. **奖励模型训练**：训练模型预测人类偏好
2. **RL 优化**：微调策略以最大化奖励
3. **PPO**：带 KL 惩罚的近端策略优化

### 挑战

- ⚠️ 奖励黑客
- ⚠️ KL 散度爆炸
- ⚠️ 人类偏好不一致

## 模型合并

### 什么是模型合并？

合并多个模型的权重以利用互补优势。

### 方法

| 方法 | 描述 |
|------|------|
| **权重平均** | 简单平均权重 |
| **任务算术** | 添加/减去任务特定权重 |
| **Fisher 合并** | 按 Fisher 信息加权 |
| **Model Soup** | 在检查点之间插值 |

### SmolLM3 方法

> "模型合并允许我们结合具有互补优势的模型，无需额外训练。"

## 关键要点

1. **SFT 是基础** —— 高质量数据至关重要
2. **DPO 比完整 RLHF 更简单** 用于偏好学习
3. **模型合并** 可以结合多个模型的优点
4. **先迭代数据质量** 再改算法
