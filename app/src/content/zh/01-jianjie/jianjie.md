# 简介

欢迎阅读 **《小语言模型训练手册》** —— 基于训练 SmolLM3 的真实经验，撰写的一份训练紧凑型语言模型的全面指南。

## 为什么写这本书？

训练语言模型是机器学习中最复杂的工程之一，需要：

- **数据工程** 大规模数据处理
- **基础设施** 管理与运维
- **研究** 与实验设计
- **迭代** 基于实验结果的持续优化

这本手册将训练 SmolLM3（一个 3B 参数、在 11T tokens 上训练的模型）的经验教训提炼成一份面向实践者的实用指南。

## 你将学到什么

| 主题 | 描述 |
|------|------|
| **训练罗盘** | 训练决策的系统化方法 |
| **小型消融实验** | 如何在规模化之前低成本验证想法 |
| **模型架构** | 重要的设计决策 |
| **数据策划** | 构建高质量训练数据集 |
| **训练执行** | 规模化分布式训练 |
| **后训练** | 对齐技术（SFT、DPO） |
| **基础设施** | 确保训练平稳运行 |

## 我们的理念

> "我们不仅展示什么是成功的——我们也展示什么是失败的。"

训练既是**避免失败**的过程，也是寻找成功的旅程。这本手册包含：

1. 我们遇到的**失败**以及如何修复
2. 我们做出的**权衡**及其原因
3. 改变我们方法的**意外发现**

## 这本书适合谁？

这本手册适合：

- **机器学习工程师** 构建或维护训练流水线
- **研究人员** 研究语言模型训练
- **学生** 学习现代 LLM 技术
- **组织** 训练自己的模型

## 如何阅读本书

你可以按任意顺序阅读，但建议：

1. **先读训练罗盘**（第2章）—— 它建立了方法论框架
2. **根据需要深入特定主题**
3. **根据需要返回参考章节**
